# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Email `info@vion-iot.com` with:

- A description of the vulnerability
- Steps to reproduce (or a proof of concept)
- The affected version and target (e.g. `vion 0.1.0, linux-musl-x64`)
- Your contact details

We will acknowledge receipt within 5 business days and keep you informed of progress toward a fix.

## Scope

This policy covers the `vion` binaries published from this repository's releases (the Linux
archives, the Windows zip, and the winget package `VION-IoT.vion`).

For vulnerabilities in the cloud API that `vion` calls, use the same address; the API is not
published from this repository.
